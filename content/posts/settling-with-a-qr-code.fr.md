title: Régler ses comptes avec un code QR, en personne
summary: Quand deux personnes sont ensemble, un code QR peut porter une demande sans qu'aucun message ne soit envoyé.
---
Parfois, le plus simple pour s'accorder est de s'asseoir ensemble devant le même écran.

## Comment cela fonctionne
- Une personne ouvre une demande ou une proposition de règlement dans DYON et choisit **Afficher en code QR**.
- L'autre la scanne avec l'appareil photo du téléphone et voit les détails avant que rien ne soit enregistré.
- L'ajout ouvre le formulaire habituel, pour qu'elle vérifie chaque champ.

## Ce qui reste privé
Les détails voyagent dans le code lui-même, et rien n'est téléversé. DYON ne l'envoie jamais à votre place.

## Quand c'est utile
- Régler une dépense partagée à la fin d'un voyage.
- Convenir d'une nouvelle date en personne.
- Remettre une note à quelqu'un qui n'utilise pas encore DYON.
